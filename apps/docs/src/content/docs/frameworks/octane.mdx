:::caution[Experimental Octane support]
Import this adapter from `@vp-tw/likftc/octane`. Likftc was tested with `octane@0.1.17` and `@octanejs/vite-plugin@0.1.17`. Octane is still alpha, so versions outside that evidence are use-at-your-own-risk; please open an issue or PR if you verify another version. Likftc source remains fully strict under TypeScript 6 and TypeScript 7; direct Node imports, SSR, and hydration are not supported.
:::
